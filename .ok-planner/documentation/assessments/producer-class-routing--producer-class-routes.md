# Routing on the acquisition error class the producer itself declares

The audit pointed the bundled filesystem claim producer (`catalog:bundled-services/claim-producer-filesystem`) at a root that does not exist, so every acquisition fails with the class that producer declares in its own handshake, and registered one node template five times changing only its error-class map. The producer's own class reached the routing surface on the terminal signal rather than being flattened into a generic one, and keying that class in the template routed the run. Whatever key did the routing, the emitted signal carried the producer's most specific class, so the classification the producer took care to make is the one the author configures a response to. The validator agrees on vocabulary: the producer's declared class registered with no warning, while an undeclared class registered with a warning naming it and the vocabularies checked. Seven checks across this way and its sibling, none failing.
