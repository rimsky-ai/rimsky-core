# Declared agent error classes route by policy or drive a subscriber

Every leg of the error-class handling answered. A declared class routed by policy settled its run fresh while the settling signal still named the class, so a policy can absorb a known failure without erasing the record of it. A declared class with no policy failed its run under its own name — `catalog:error-classes/agent/refused` — and a wildcard subscriber over the agent error family ran on that failure. A class outside the executor's declared vocabulary was refused at the callback surface, and the dispatch failed under a declared class instead, so the vocabulary an operator subscribes against is closed rather than whatever an agent chooses to report.
