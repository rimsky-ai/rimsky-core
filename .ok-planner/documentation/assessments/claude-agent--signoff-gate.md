# The sign-off gate binds a signature to the output it covers

The gate held in all three directions the run drove. The node whose signature covers the value it writes committed that same value. A signature bound to another dispatch failed as sign-off unobtained, and so did a signature over a value the run never wrote. The gate therefore checks the binding between the signature and the real output, not merely that some signature was presented — which is what makes it worth putting in front of an agent's work.
