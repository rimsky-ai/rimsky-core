# Creating a movable name for a template hash

The audit registered two definitions differing by one bound, so they carry different hashes, then created a movable name with `catalog:cli-verbs/rimsky tag create` bound to the first hash. An instance created through the name bound to the tagged hash, so the name is usable as a template reference wherever a hash is, not merely recorded beside it. The operator gets a stable deployable name over content-addressed definitions.

## Unverified remainder
