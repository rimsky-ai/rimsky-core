# Images reference

## Purpose
An operator running rimsky or its bundled services from images opens it to learn each image, what it runs, its commands, the paths it expects, and the ports it listens on. They close it able to run and wire the images.

## Covers
- every public image
- every public image command
- every public image path
- every public port
- each bundled executor image's attribute contract: the attribute keys it reads and the shape it writes back
- every public bundled service
