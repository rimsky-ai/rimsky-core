# Configuration reference

## Purpose
An operator opens it to write rimsky.yml, the supervisor config, a bundled service's config, or the CLI's own config files. They close it knowing every key, its type, default, and effect.

## Covers
- every public config key
- every public service-config key
- every public publisher kind
- every public publisher config key
