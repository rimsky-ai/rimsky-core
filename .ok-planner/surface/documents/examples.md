# Examples

## Purpose
A template author or operator who wants to see one behavior in isolation opens the example for it: the template, the verbs or routes that drive it, and what the product does. They close it able to reproduce that behavior against their own deployment. Each example shows a way through the public surface that ran at this release; a behavior that did not run is not shown.

## Covers
- every supported story's demonstrated way through the public surface, one example each
- the public template keys, CLI verbs, HTTP routes, and compose-manifest keys each example drives
