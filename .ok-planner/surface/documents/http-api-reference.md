# HTTP API reference

## Purpose
An integrator opens it to call the control API, the supervisor callback routes, or the sensor-webhook ingress directly. They close it knowing the method, path, request and response shape, and the auth posture of every route.

## Covers
- every public HTTP route
- the event kinds the event-log routes report
