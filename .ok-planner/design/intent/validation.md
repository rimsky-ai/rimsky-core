## Net position

- **lifecycle_subscriber is a real fourth validation role** (user ruling 2026-07-17): the registration pipeline must invoke Validate template-wide on every registered lifecycle subscriber advertising the role — the plumbing (proto context, client method, conformance happy-path) exists end to end, the conformance suite already obligates subscriber authors to implement it, and a store receiving a template's lifecycle events has a legitimate stake in rejecting an unsupportable template at registration, when rejection is cheap. Current RunValidationPipeline covers only executor/claim_producer/publisher (queued fix-code). The two artifact-tier 3-role entries below are superseded on this point.

- **The validation-timing model is a layered pipeline**: template registration (governed by an explicit operator strictness mode: all — default, hard-fail on any unvalidatable reference — | available | none), then instantiation as the **mandatory** gate (statically-knowable attribute config validated against every referenced service's schema, value constraints included), then dispatch-time post-substitution attribute validation (invariant 12), then commit-time validation of the executor's write-back. Whatever a relaxed registration mode skips, instantiation enforces (2026-06-06 / 2026-06-08, comprehensive-gap-closure / corpus-bootstrap).
- Invariant 12 (validate twice) is non-negotiable: attributes validate at dispatch post-substitution before the executor call AND at commit on executor writeback (2026-05-04, modeling-layer-contract; reaffirmed by the user's exact pipeline rule 2026-06-15, c60b550a, transcript).
- **Explicit over implicit is the governing style**: no silent defaults (subscription flags required; on_commit/on_give_up required), no implicit edges (auto-subscribe retired; every substitution ref needs a covering declared subscription), closed enums rejected loudly at the earliest boundary (cascade_mode, sync_strategy, tls), structured errors with actionable content (2026-06-14, 37e2ea5e, transcript, user; 2026-05-06, fs-store-pick-policy-action-vocabulary).
- **Pre-v1 retirement means pure removal**: no back-compat, no remnants, no code that detects retired shapes to emit migration errors — retired surfaces fail through generic paths (unknown field, taxonomy enforcement, registry lookup); the code carries no knowledge the features existed (2026-06-14, bfc9febb, transcript, user).
- The Validation cross-cutting mix-in is the protocol for service-side registration validation: one Validate RPC with a role discriminator, deliberately not named ValidateUserdata (the request carries claim bindings, attribute schemas, config beyond userdata); rimsky forwards opaque bytes and receives a verdict (2026-05-15, data-platform-extensions). It must be honored for every peer kind — executor, publisher, claim producer (2026-06-11, last-mile-stability).
- One JSON Schema validator idiom repo-wide: github.com/santhosh-tekuri/jsonschema (Go) / ajv (TS); no second validator introduced (2026-05-08, platform-extensions; reaffirmed 2026-07-03, 8a8539a4, transcript, user).
- Inertness boundaries hold through validation: message body bytes are not validated at receipt (body_schema serves registration-time ref checking; real validation happens when a receiver pulls values at dispatch); defaults/overrides validators inspect only routing keys, never fragment values (2026-06-14, bfc9febb, transcript, user; 2026-05-19, multi-instance-template-ergonomics).

## Required behaviors (open promises)

- **Dispatch-phase attribute gate (invariant 12)**: the runtime dispatch path runs Validate/CheckEffectiveAttributesSchema on resolved attributes — "copy forward from the last run (already valid), or seed" → "apply substitutions" → validate → run executor → validate write-back, no extra filtering steps (2026-06-15, c60b550a, transcript, user quote). Currently under an active fix-code ruling (see drift-fight record).
- **Registration reference-validation mode**: explicit RefValidationMode all|available|none spanning executors, claim-producers, locks, subscriptions; default all; rejection messages are self-documenting — they name the active mode, state it made the unprovisioned reference fatal, and name templates.ref_validation_mode with its relaxed settings (2026-06-06, comprehensive-gap-closure; 2026-06-11, last-mile-stability, artifact).
- **Mandatory instantiation gate**: POST /instances validates statically-knowable attribute config against every referenced service's advertised schema including value constraints (e.g. minimum bounds), refusing the create with an error naming the offending attribute and constraint; nothing persisted or run (2026-06-06 / 2026-06-08, artifact).
- **checkAttributesSchema registration rules**: each property declares at most one of source:/default:; a property must have source:, default:, executor-schema readOnly: true, or fall under the fourth condition — unenumerated by an executor schema that doesn't constrain it (no properties block, or additionalProperties not false), where the executor has delegated naming authority; the author cannot claim readOnly the executor's schema doesn't grant; enumerated properties fully checked (2026-05-20, userdata-collapse-into-attributes; 2026-05-28, quality-of-life-features, artifact).
- **required: semantics**: fires only at the commit-time gate for executor-written properties the write-back failed to populate; input attributes gate via strict directives / non-nullable types instead (2026-05-20, userdata-collapse-into-attributes, artifact-only).
- **Carry-forward flows verbatim**: no projection filter; schema validation honoring the author's declared additionalProperties enforces the bag's shape (2026-06-15, c60b550a, transcript). Carry-forward is default-on for all properties, with visibility mitigations (docs, registration surfaces stateful properties, shipped schema descriptions) (2026-06-14, 752fe200, transcript, user).
- **Substitution-ref coverage check**: implicit auto-subscribe is gone; an uncovered substitution ref fails registration with structured error kind substitution_ref_uncovered naming receiver, ref text, property path, plus a copy-pasteable suggested subscribes: entry — "the templte fails validation" (2026-06-14, 37e2ea5e, transcript, user; closed as delivered in v0.10.0 commit 19770b30, 2026-06-24, 3b1066c7).
- **Subscription flags have no defaults**: wake_on_change and force_upstream_refresh are both required on every subscribes: entry; registration rejects an entry missing either (2026-06-14, 37e2ea5e, transcript, user). instance: true + force_upstream_refresh: true is rejected as incoherent (2026-06-14, 37e2ea5e, transcript).
- **Asymmetric wildcard coverage**: attribute/* covers per-field reads; a per-field subscription does NOT cover a whole-bag pull (2026-06-14, 37e2ea5e, transcript).
- **messages ≡ nodes with different validation**: 'messages' is a lexical alias for 'nodes', type-checked at registration (messages-prefix names must be declared message-virtual nodes, nodes-prefix must be non-message nodes); exactly one substitution pipeline underneath, no runtime branching; the coverage check treats both identically against the combined set; undeclared {{messages.bar.x}} rejected with the offending name in the error body (2026-06-18..19, 9fb55f08 / 8a3b8c19 / 8e7e4c10, transcript, user).
- **Message-schema gates**: message refs validate at registration in both directions (reading an undeclared field rejects; writing a field the destination body schema lacks rejects); body bytes NOT validated at receipt (2026-06-14, bfc9febb, transcript, user). The empty "" message type is runtime-reserved: seeded implicitly with a null body schema; an author-declared "" entry is rejected at registration (2026-06-15..17, 4c42fe5b / b95ff4a7, transcript).
- **ErrMissingSource is not frame-blocking**: fallback literal substitutes, lenient lifts to null/empty, optional omits; only a required strict ref with no fallback escalates to template_resolution_failed (2026-06-14, 37e2ea5e, transcript, user).
- **Terminal-tag double gate**: executors declare tags via ObservabilityCapabilities.declared_tags; gate-1 at registration compares CEL tag literals against declared_tags (warning on undeclared); gate-2 at runtime rejects any settling outcome carrying an undeclared tag as executor_protocol_violation — the runtime gate was explicitly ratified as a plan step so it could not be silently dropped (2026-06-16..17, 055468fc / b31002b8, transcript).
- **Park subscriptions are a registration error**: users can only subscribe to success and error signals; park payloads carry no attributes_delta (2026-06-24, 8a8539a4, transcript, user).
- **One emit method per terminal kind**: every signal type-path binds exactly one canonical payload schema; exact-type CEL predicates parse-check field references against it at registration; divergent inline payload construction is a defect (2026-06-24, 8a8539a4, transcript, user).
- **CEL rules**: all when: expressions parse at registration, syntactically invalid ones reject; exact type-path subscriptions get field-misspelling diagnostics (via AST walk over payload.<field> selects); trailing-* prefix subscriptions bind payload as dyn with no field warnings — the author opted into imprecision; type-path wildcards are trailing-* only, no positional wildcards, no glob (2026-05-23, signal-taxonomy-and-policy-decoupling, artifact).
- **Error-class range-check, advisory not blocking**: validator checks error_types: keys against the union of executor-declared classes, the acquire/* synthetic family, and reachable producers' declared classes; unattributable keys register with an advisory warning, never hard rejection; runtime-synthesized classes are allow-listed; declared trailing /* wildcards honored (2026-05-23 shims; softened 2026-06-11, last-mile-stability, artifact — supersedes earlier hard rejection).
- **Template lint**: POST /templates/validate + `rimsky template lint <file>` run the full registration validation pipeline (static schema check, executor schema cross-check against the live discovery cache, Validation-RPC fan-out) with nothing persisted; exit codes 0 clean / 1 validation drift / 2 usage error; diagnostics to stderr, bare "ok" to stdout (2026-05-28, quality-of-life-features, artifact).
- **Registration accumulates all errors**: node.ValidateTemplate returns the full validation_errors array; it does not bail on the first error (2026-05-28, quality-of-life-features, artifact).
- **Validation mix-in pipeline**: static rimsky-side schema check first (no RPC), then Validate RPC per advertising service; error-severity findings block registration with the finding surfaced, warnings surface without blocking; warnings merge into both register and validate endpoints' validation_warnings and warnings_as_errors=true trips on them; all three peer kinds honored (executor observability carries validation_supported_roles) (2026-05-15, data-platform-extensions; 2026-06-08, corpus-bootstrap; 2026-06-11, last-mile-stability, artifact).
- **Dry-run is real validation**: dry-run of template:register runs the Validation mix-in RPCs faithfully (side-effect-free), skipping only the DB insert; synthetic response carries dry_run:true with marked placeholder IDs; mode:dry_run ignored on reads (2026-05-15, control-plane-mcp-and-auth, artifact-only).
- **late_bind_services**: names in the list bypass registration-time existence checks and expected-attributes schema validation; default empty list keeps strict behavior — "Opt-in laxness, not silent"; the deferred check happens at dispatch against the spawned binary's Capabilities schema, mismatch → contract_mismatch (2026-05-24, host-agent-and-proxy, artifact).
- **Resume-overlay both-layers validation**: shape + pre-merge validation against the dispatch's effective schema at control-api (400 ErrResumeOverlayInvalid), then defense-in-depth re-validation at the supervisor routed through template_validation_failed; effective schema comes from the hit-time snapshot's effective_schema field, absent → warn and defer to the supervisor gate (2026-05-24, instance-debugger, artifact).
- **cascade_mode parse-time enum check**: unknown values rejected at template-parse with a field-level error naming the value and the four valid options; empty accepted, defaults server-side to most-recent (2026-06-22, 10cf843b, transcript).
- **Coalesce multi-type warning**: the validator warns when a coalesce-mode node declares two or more distinct message types (coalesce cancels ALL pending messages regardless of type), pointing at backlog mode (2026-07-06, 3f71f90a, transcript).
- **kind xor executor**: a node declares kind: <name> or executor:, never both — registration error (2026-06-14, 752fe200, transcript).
- **Compose manifest service names**: every executors: / claim_producers: key must match ^[a-z][a-z0-9-]{0,62}$ at flag-parse time, failing with a clear error instead of a deep-stack boot error (2026-06-14, f0176bde, transcript).
- **Bundled-store config-load validation**: pick-policy fields required with no defaults; unsupported action/strategy combinations rejected (pop + on_open; pg pop_and_move/pop_and_delete); same-filesystem device-ID check for pop_and_move targets; ValidationResult struct with separate Errors and Warnings, constructors fail on errors, warnings logged (2026-05-06, fs-store-pick-policy-action-vocabulary, artifact — full detail in the claim-producer dossier).
- **Retired-config-key hard errors at the YAML boundary**: operator configs using stores: or single-value write_semantics: fail startup with a precise error directing to the canonical key; old proto wire shapes error at the gRPC layer with no fallback (2026-05-12, nomenclature-resolution, artifact; the stores: directing error explicitly retained 2026-06-19, a02fe167, transcript — see Conflicts).
- **Backfill target validation**: backfill:create rejects with 400 a target_node that is not a fan-out node wired to accept the partition override; dry-run applies the same validation (2026-05-29, console-upstream-auth-audit-and-fixes, artifact — tightened from the earlier warn).
- **Sub-graph registration rejections**: recursive sub-graphs (subgraph_recursion_unsupported, HTTP 400), missing entry/exit, disconnected internals, main declaring entry/exit, internals referencing outer nodes, entry==exit; encapsulation enforced at canonicalization, not runtime (2026-05-15, data-platform-extensions; 2026-06-02, acceptance-coverage-recovery, artifact).
- **carry_verbatim_requires_single_child**: the carry-verbatim aggregation policy requires exactly one child, enforced at template validation as a checked rejection class (2026-06-11, last-mile-stability, artifact).
- **tls enum**: exactly off | required (empty → off); any other value is a config error naming the entry (2026-06-11, last-mile-stability, artifact).
- **Fan-out registration gates**: referenced claim declared on the node; producer advertises supports_split_scope; producer's Validate accepts the partition_request shape when advertised; lifetime: durable requires the data_processing protocol (2026-05-15, data-platform-extensions, artifact).
- **{{params}} in tags**: tag references to undeclared ParamsSchema keys reject registration; non-params directives in tags reject (2026-05-19, multi-instance-template-ergonomics, artifact-only).
- **Parked-nodes ?reason= validation**: unknown ParkReason values return 400 with the list of valid options (2026-05-14, subscription-cascade-and-quality-of-life, artifact-only).
- **frame_timeout_ms >= 60000**: schema CHECK constraint (Postgres + SQLite); smaller values unreachable through the DSL (2026-05-05, reactive-loops-and-lifecycle-handlers, artifact-only).
- **write_semantics_envelope subset check**: operator-declared envelope must be a subset of the producer's Capabilities envelope, startup fails fast; every template-referenced producer and named lock must be declared in config (2026-05-04, modeling-layer-contract, artifact-only).
- **Verifier severity partition**: failing severity:warning is non-blocking (recorded on observability); everything else including typos blocks — the exact-string footgun is a tracked open tension, not a resolved design (2026-06-08, corpus-bootstrap, artifact).
- **verifier-shape-checks bundled executor**: Apache-licensed Go executor doing data shape checks (no_nulls, pk_unique, value_in_set, regex_match, numeric_range, ...), replacing the retired in-graph graph/qualityrule package, advertising both executor and validator roles so control-api can cross-check resolved attribute schemas at registration (2026-06-15, 8c66c02c, transcript — flagged as awaiting promotion to a durable decision).
- **Signoff gate layering**: claude-agent report_complete enforces schema validation first (max_schema_corrections) then the signature gate (max_signoff_attempts), each with its own retry budget; agent/signoff_unobtained is in declaredErrorClasses so operators can route it (2026-06-04, claude-agent-signoff-gate, artifact).
- **Acceptance-gate discipline**: every prominently-claimed capability has a real gate driving the real entry point with the real component (no stub standing in for the thing under proof); invariant gates are coupling-proven (neuter enforcement, confirm red, restore); every runtime fix carries the end-to-end test that would have caught it (2026-06-02, acceptance-coverage-recovery / rimsky-core-remediation, artifact).

## Intentional absences

- **Detection of retired shapes**: no validator rule naming hard_dep, no hard_dep_field_removed error kind, no STORY-trigger-message-payload-rejection, no migration-redirect errors — "erase it completely instead"; retired surfaces (coalesce, frame: modifier, message topic kind, kind: invalidate, {{trigger.message.payload}}) fail through generic paths (2026-06-14 / 2026-06-18, 37e2ea5e / bfc9febb / 9fb55f08, transcript, user).
- **Implicit auto-subscribe from substitution reads, and the hard_dep flag** — both retired; coverage is required, not auto-generated (2026-06-14, 37e2ea5e, transcript, user).
- **Message-body validation at receipt** — deliberately absent; validation happens at the receiver's dispatch through the attribute gate (2026-06-14, bfc9febb, transcript, user).
- **Deploy-time subscription-cycle rejection** — removed: under the wait-set model a cycle is a terminating defer-loop across frames (2026-05-14, subscription-cascade-and-quality-of-life-notes).
- **drift_summary (category-grouped validation errors)** — deferred to its own spec; needs a stable error-code taxonomy first (node.ValidationError is free-text {Path, Msg}) (2026-05-28, quality-of-life-features).
- **${VAR} / $VAR detection in template values** — declined; "one more thing to maintain" (2026-06-24, 3b1066c7, transcript, user).
- **tls: optional** — deleted; opportunistic TLS is not a real gRPC client mode (2026-06-11, last-mile-stability).
- **Author override of the empty-message entry point** — out of scope; "" is runtime-reserved, override would be a separate later spec (2026-06-15, 4c42fe5b, transcript, user).
- **Extra additionalProperties strictness just to catch stray hard_dep** — declined; unknown-property handling is whatever the existing attribute-schema validator does (2026-06-14, 37e2ea5e, transcript, user).
- **Silent implicit retry on acquisition failure** — reversed: no acquire/unavailable entry means give_up with a precise error class; the validator emits an informational warning when a node declares claims but no acquire/unavailable policy (2026-05-23, signal-taxonomy-and-policy-decoupling).
- **ValidateClaimantUserdata (agentic-platform sketch Part 3)** — superseded by the Validation cross-cutting mix-in; the sketch's other parts are consumer-side patterns, not platform surface (2026-05-15, control-plane-mcp-and-auth).
- **Event-based validation surfaces** — event/<name> subscription paths, nodes.<X>.event.<name> substitution, the on_event: handler map, and declared_events (renamed declared_tags) are all retired in favor of terminal/* + payload.tags CEL and subscribes: (2026-05-19, crimefinder; 2026-06-16..17, 055468fc / b31002b8, transcript).
- **Registration-time userdata validation as a surface** — the entire userdata wire surface was removed (ExecuteRequest.userdata, ExecutorContext.userdata deleted; userdata_schema → expected_attributes_schema); all values flow through attributes, no migration shim (2026-05-20, userdata-collapse-into-attributes).

## Corrections and restorations (drift-fight record)

- **Invariant-12 dispatch gate silently dropped**: the June-21 message-receiver refactor removed the Validate/CheckEffectiveAttributesSchema call from resolveAttributes, leaving the validation-error classification legs unreachable and the invariant unenforced. Adjudicated fix-code — rewire the check (findings 111 and 128, one defect) (2026-07-13, 3f71f90a, transcript).
- **Carry-forward projection filter backed out**: a code-review "hardening" that projected carry-forward through the schema's properties block was ruled either redundant or an override of the author's declared permissiveness; the seed flows verbatim and post-substitution schema validation enforces shape (2026-06-15, c60b550a, transcript).
- **execSchemaVisible divergence**: checkAttributesSchema skipped the source/default/readOnly rule when the executor schema wasn't visible at registration — unsanctioned by spec (2026-05-21, userdata-collapse divergences); later reconciled by documenting the fourth (delegated-naming) satisfying condition (2026-05-28, quality-of-life-features).
- **claim_scope split brain**: registration accepted only {{claim.X.scope}} while the runtime resolved only {{claim.X.claim_scope}} — no spelling passed both. Fixed: claim_scope canonical end to end, legacy spelling rejected at registration (2026-06-06, comprehensive-gap-closure).
- **Static-validator warnings never connected**: computed but reaching neither response; now merged into register/validate validation_warnings, and warnings_as_errors trips on them (2026-06-11, last-mile-stability).
- **Validation mix-in ignored two peer kinds**: executor and publisher validation_supported_roles were silently treated as empty — "a gap, not a design"; fixed with the executor-observability field addition (2026-06-11, last-mile-stability).
- **claude-agent schema mismatches**: userdata schema declared camelCase while the parser read snake_case (aligned on snake_case); the executor registered only NodeExecutor and not ExecutorObservability, so its schema and declared events never reached discovery and dispatch-time validation silently fell through — executors must register both services (2026-05-08, platform-extensions notes).
- **Sensor→publisher naming residue in validation surfaces**: SensorContext/sensor_name/ValidateSensor/role "sensor"/SensorHappy swept to Publisher* forms across the validation pipeline, conformance runner, and publisherkit; bundled instance names like sensor-cron correctly remain (2026-06-19, 08d65bfe / 8a3b8c19, transcript — supersedes the 2026-05-17 deliberate retention of the 'sensor' role string).
- **policy_give_up unreachable from stale**: under on_acquire_unavailable resolve error, the give_up chain silently failed on a swallowed illegal-transition error; NextState extended (stale → failed). Open follow-up: policy_retry / policy_invalidate still rejected from stale, undecided whether to support or validator-reject (2026-05-05, reactive-loops notes, artifact-only).
- **False bail-on-first-error report refuted**: a third-party claim that registration stops at the first validation error was investigated and found false — the real gap was validate-without-persist, delivered as template lint (2026-05-28, quality-of-life-features). Precedent: findings can assume drifted expectations and be refuted.
- **CEL binding divergence (accepted)**: payload bound as a dyn-valued map rather than registered Go native types; exact-type field diagnostics via AST walk — judged cleaner, avoids Go type names in operator templates (2026-05-23, signal-taxonomy divergences).
- **carry_verbatim N=1 check relocated**: spec placed it at canonicalization; implementation enforces at template validation (the only reachable multi-child shape is fan_out:), surfacing in the registration response (2026-06-11, last-mile-stability).
- **YAML null for pick-policy actions**: parse-level rejection impossible under yaml.v3; caught by the downstream action validator as an unknown (empty) action (2026-05-06, stores-pick-policy notes).
