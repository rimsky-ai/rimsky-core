# Intent Dossier: supervisor

Distilled 2026-07-13 from session transcripts (2026-06-12..2026-07-13) and ok-planner
history artifacts (2026-05-04..2026-06-11). Transcript tier outranks artifact tier;
later intent supersedes earlier. Part of the drift-remediation intent ledger.

## Net position

- The supervisor is the load-bearing runtime surface — acquisition tx, dispatch, terminal resolution, callback HTTP server, liveness, claimant-guarded release, verify-before-run — and is deliberately the only runtime binary promoted to a concept; the scheduler is a thin advisory-lock-gated cron loop, not a concept (2026-05-11, design-log-convergence, artifact).
- Verify-before-run holds in both limbs: immediately before invoking a service that acts on a claim, the runner re-reads claimed_by and bails if ownership moved; and after the acquisition tx commits, ownership is re-read before dispatch — a claim stolen between commit and dispatch emits orphaned_claim_lost_race and makes no Execute call (2026-05-04, foundation-contract, artifact; 2026-06-02, acceptance-coverage-recovery, artifact).
- Liveness is quiet-period based, not heartbeat based. Sync dispatches: the gRPC connection plus sync_rpc_deadline is the liveness signal. Async dispatches: opt-in keepalive feeding one last_progress_at tracker via two channels — POST /v1/runs/{run_id}/keepalive and attribute writebacks (incidental keepalives). All heartbeat machinery is deleted (2026-06-16..17, 055468fc / b31002b8; 2026-06-21, 21306ffe, transcript).
- Three orthogonal per-node dispatch deadlines, each 0 = disabled: sync_rpc_deadline (default 30s, error class executor_sync_timeout), max_quiet_period (default 0, executor_quiet), max_runtime (default 0, max_runtime_exceeded, wins over quiet). Effective per-node values are denormalized onto rimsky_node_runs at async-ack registration (2026-06-17, b31002b8, transcript).
- The async-callback registry is persistent on the dispatch row (rimsky_node_runs.async_ack_id + async_ack_registered_at, unique partial index); the in-memory registry is a read-through cache only; ack registration and the transient/await_async emit are atomic in one transaction, so pending callbacks survive supervisor restart (2026-06-17, b31002b8, transcript).
- The async-callback body is the wire AsyncCallbackBody: a oneof outcome (exactly one of success / error / park), protobuf-JSON field name as discriminator; the legacy {type: complete|blocked|errored} shape is rejected with a precise error; AwaitAsyncCallback is deliberately excluded from the oneof (a webhook cannot chain); the events array was later removed with named events (2026-05-12, nomenclature-resolution, artifact; events removal 2026-06-16, 055468fc, transcript). The ack id comes from the URL path (${callback_url}/v1/callback/{async_ack_id}), not the body (2026-05-19, crimefinder, artifact).
- Callback determinism is a blessed invariant: a callback is honored iff the run's phase is active or held at processing time, checked with a row lock in the same tx as the state mutation; any other phase yields ack-but-noop with HTTP 200 and an authoritative ack_status field (2026-05-22, fan-out-safety-scope-first, artifact). A callback for a run already flipped terminal must be rejected (2026-06-17, b31002b8, transcript).
- Retry loops are deterministic from the operator's point of view: no hidden supervisor-side caps. The single sanctioned supervisor default is a retry cap of 10 for infrastructure-class errors with no operator-declared policy; an operator-declared MaxRetries always wins (2026-06-22, 10cf843b, transcript). The deployment-level retries-without-progress cap is a supervisor default, not a scheduler default (2026-06-11, last-mile-stability, artifact).
- Bookkeeping must be fast: scheduler tick 250ms and claim_poll_interval 200ms are production defaults; timing failures under stub executors are rimsky bugs, not test-tolerance problems; nothing may stall the scheduler (2026-06-21, 21306ffe, transcript).
- Role selection: rimsky-entrypoint honors its command argument — no command runs all three roles in one process via lib/control/launch (the single shared wiring shape for unified and single-role deployments); a role name runs only that role; migrate runs exactly once in a split deploy (2026-06-02, rimsky-core-remediation, artifact; launch package 2026-06-12, last-mile-stability-completion-report, artifact).
- Callback advertise vs bind is a real concept: the supervisor binds 0.0.0.0 but must stamp an externally reachable URL into ExecuteRequest.callback_url (cfg:callback.advertise_host / env, e.g. host.docker.internal) (2026-05-19, crimefinder, artifact). Ratified direction: fail fast at startup when advertise is empty and bind is wildcard, rather than silently stamping http://0.0.0.0:9100; collapse the four host/port scalars into a single advertise base-URL (2026-06-21, ecde6dd1, transcript).
- The supervisor is service-topology-blind: the host-agent proxy is a normal multi-protocol service; no tunnel-awareness leaks into the supervisor, dispatch path, error vocabulary, or graph processing. Late binding rides a per-call x-rimsky-service-name metadata header, a LateBindResolver chained after StaticResolver (DispatchContext param), Registry.GetWithContext with functional options, and OR-clause claim-query admits (2026-05-24, host-agent-and-proxy, artifact).
- The supervisor owns lifecycle-subscriber firing for the transitions it commits: OnRunScopeTerminal for sub-graph and fanout-partition run-scope-terminal fires from the supervisor (synchronous, in-tx side), via a LifecyclePeersForSpec function pointer (runtime may not import control/); control-api keeps template/instance events and main-scope terminal (2026-05-24, host-agent-and-proxy, artifact).
- Fan-out parents do not dispatch their own executor; children dispatch independently and the parent settles per the aggregation policy snapshot. Pure-cascade (NULL-executor) rows are excluded from dispatch eligibility unless they carry required_stores (2026-05-15, data-platform-extensions, artifact).
- Session/resume vocabulary is executor-specific and lives behind the executor protocol; the supervisor, scheduler, and core persistence must not know anything about resuming (2026-06-14, 752fe200, transcript; resume-context removed in the 2026-06-16 executor-protocol-coherence spec).
- Instance control: soft pause only (paused column; candidate selection gains AND paused = false; in-flight runs go to terminal naturally); pause/resume are non-idempotent 409s; POST /instances on a deployed template creates only the row — the supervisor dispatches nothing until a message lands (STORY-instance-create-is-idle); force-terminate drives in-flight runs to terminal through the real lifecycle path (2026-05-24 instance-debugger + 2026-06-08 corpus-bootstrap, artifact; instance-create-is-idle 2026-06-16, 4c42fe5b, transcript).
- Breakpoints: exactly two supervisor checkpoints — before_dispatch (post-L5 merged bag, before Execute) and after_terminal (at the two runApplyTerminal callers, after the terminal tx commits, before cascade walks); two modes (pause default, notify_only); cross-process resume via 250ms DB polling of rimsky_breakpoint_hits — binaries coordinate exclusively through the database (2026-05-24, instance-debugger, artifact).
- Known accepted gaps (recorded as tensions, not drift): unreachable-service-row-stall (a dispatch row admitted by no supervisor sits in queue indefinitely, no synthetic error class); internal-service-auth-unspeced (no process-to-process auth; deployment-level network isolation); the producer-verb (Commit/Abandon) call chain at terminal has no per-verb deadline — a defensive timeout was recommended and deliberately not landed (2026-05-24 host-agent-and-proxy; 2026-05-04 layer-crystallization, artifact) `(artifact-only)`.

## Required behaviors (open promises)

- Verify-before-run, both limbs, including the post-commit re-read emitting orphaned_claim_lost_race with no Execute call (2026-05-04 foundation-contract; 2026-06-02 acceptance-coverage-recovery, artifact): "the runner MUST bail without acting on the claim."
- Callback determinism: phase ∈ {active, held} checked atomically (SELECT FOR UPDATE) with the state mutation; ack-but-noop (HTTP 200 + ack_status) for late/stale callbacks — hard-erroring was explicitly rejected to avoid retry storms (2026-05-22, fan-out-safety-scope-first, artifact).
- AsyncCallbackBody parsing: exactly one outcome key; legacy discriminator and wrapper shapes rejected with a precise error (2026-05-12 nomenclature-resolution, artifact; exactly-one enforcement 2026-05-08 notes, artifact).
- Persistent async-ack registry: production paths call RegisterAsyncAck in the same tx as the transient/await_async emit; a callback POST survives supervisor restart (invariant persistent-registry-survives-restart); a conformance scenario restarts the supervisor between registration and callback (2026-06-16..17, 055468fc / b31002b8, transcript): "right. fix everything. implement every missing thing. we want 100%."
- Keepalive endpoint POST /v1/runs/{run_id}/keepalive: cancel_token auth, no body, bumps last_progress_at, 204/404/401/400 (2026-06-17, b31002b8, transcript).
- Attribute writebacks and scratch writes bump last_progress_at in the same transaction as the write (2026-06-17, b31002b8, transcript).
- Deadline enforcement: max_runtime actually enforced; max_quiet_period default 0 = disabled (a 15m implemented default was corrected as drift); max_runtime wins when both fire (decideExecutorDeadlineRelease) (2026-06-17, b31002b8, transcript).
- Quiet-period reaping as the dead-supervisor mechanism: SweepExecutorDeadlines releases claims on per-row deadline breach; re-assignment is the normal pending-queue claim path (2026-06-21, 21306ffe, transcript): "the new mechanism is quiet-period. which we like better than heartbeat."
- /v1/health computes each supervisor's active node count on demand (JSON field name kept for CLI compatibility); no cached counter (2026-06-21, 21306ffe, transcript).
- Fast production defaults kept: 250ms tick, 200ms claim poll; races surfaced by the faster cadence are bugs to fix, not reasons to revert (2026-06-21, 21306ffe, transcript).
- No hidden retry caps; infra-class-only default cap 10 with operator MaxRetries winning (2026-06-22, 10cf843b, transcript).
- Entrypoint role honoring and the migrate-exactly-once story for split deploys (2026-06-02, rimsky-core-remediation, artifact).
- Parked-node handling: SelectCandidates/ClaimDispatchRow filter phase='pending' so parked rows are never claimed directly; wake only via wakeParkedNode; resume transitions parked→stale (ReasonHandlerResume) so the waking supervisor need not run an executor pool; all invalidate sources flow through the single UnifiedInvalidate path that wakes parked targets (2026-05-08, platform-extensions-for-agent-consumers, artifact).
- Parked auto-wake at resume_at: the parked-node sweep re-dispatches at resume_at (the mechanism http-node's 429 Park with PARK_REASON_SNOOZE reuses; no new park machinery) (2026-06-06, comprehensive-gap-closure, artifact) `(artifact-only)`.
- Recovery-aware dispatch fields: the supervisor populates prior_dispatch_id / prior_dispatch_disposition on every superseding dispatch, persisted via migration 012 so a restarted supervisor re-emits them; conformance-tested (2026-05-22, fan-out-safety-scope-first, artifact) `(artifact-only; see Conflicts — disposition enum names heartbeat-era causes)`.
- DataProcessing wiring: supervisor dials producer clients at startup (DataProcessors registry threaded through config, run args, callback server); BeginCandidate at sub-claim acquisition in the same tx as the sub-claim row; CommitCandidate at leaf success; AbandonCandidate on failure paths; StoreHandle.CandidateHandle reaches the leaf (2026-05-15 design + 2026-06-02 remediation, artifact).
- Late-binding chain per the host-agent design: per-call header, resolver chaining, GetWithContext, admit OR-clauses; static-only registrations bit-identical (2026-05-24, host-agent-and-proxy, artifact) `(artifact-only)`.
- Supervisor-side lifecycle machinery: dials subscribers at startup via the shared dialLifecycleSubscribers walker, own LifecycleRegistry, fires OnRunScopeTerminal synchronously after run-scope close, DB-tracked idempotency across both firing sites (2026-05-24, host-agent-and-proxy, artifact) `(artifact-only)`.
- Breakpoint contract: two checkpoints at the named positions; pause blocks the runner with 250ms hit-row polling; per-iteration block for multiple matching pause breakpoints with matchers evaluated against a function-entry snapshot of the post-L5 bag; breakpoint deletion cascade-deletes hits and unblocks pollers without deadlock (scenario-tested); after_terminal wired at the runApplyTerminal callers to preserve no-tx-held-across-wait (2026-05-24, instance-debugger, artifact) `(artifact-only)`.
- SelectCandidates paused-instance join locks FOR UPDATE OF d SKIP LOCKED — no instance-row lock per tick (2026-05-24, instance-debugger divergences, artifact) `(artifact-only)`.
- Callback advertise fail-fast: startup error when advertise_host is empty with a wildcard bind, instead of stamping 0.0.0.0; single advertise base-URL (TLS/path-prefix capable); conformance loopback rewrite made consistent with production (2026-06-21, ecde6dd1, transcript — ratified sketch; verify landed).
- compose run graceful shutdown: soft drain, hardcoded 5s grace, SIGTERM→SIGKILL for in-flight and spawned children, second Ctrl-C hard exit, exit 130/2 (2026-06-13, 65667e33, transcript); compose run splices callback.port: 0 so the kernel picks the callback port; verbatim-supervisor-yml writer kept under a drift-pin test (2026-06-14, f0176bde, transcript).
- Instance lifecycle end-to-end: pause stops claiming, resume restores, force-terminate reaches terminal through the real lifecycle path (never a direct row write), delete refused until terminal (2026-06-08, corpus-bootstrap, artifact) `(artifact-only)`.
- Asset/backfill dispatch honesty: re-materialization causes a real producing-node dispatch; backfill materializes against the partition-selector override and cancel aborts in-flight partitions through the real cancel path (2026-06-08, corpus-bootstrap, artifact) `(artifact-only)`.
- Config split: RIMSKY_SUPERVISOR_CONFIG is supervisor tuning only; RIMSKY_CONFIG is the deployment-shape config for all binaries (2026-05-04, layer-crystallization, artifact) `(artifact-only)`.
- ResyncSensorWatches on supervisor startup: promised in the 2026-05-15 plan, explicitly recorded as never wired (no SensorRegistry threaded through supervisor startup), deferred, and no later entry records wiring it — a promised resync-after-restart behavior may exist only as an uncalled helper (2026-05-15, data-platform-extensions, artifact) `(artifact-only; verify against code — likely a restore-or-formally-retire item)`.

## Intentional absences

- All heartbeat machinery: the heartbeat ticker/doHeartbeat, SweepStaleHeartbeats, the 5x-heartbeat_interval cutoff (old blessed-invariant 6), HeartbeatInterval/HeartbeatTimeout config, last_heartbeat_at columns on rimsky_node_runs / rimsky_supervisors / rimsky_claim_handles (dropped, migration 013), livenessTick, heartbeat_interval_ms keys, and the cached active_node_count column (dropped, migration 014). Rationale: an executor could fake heartbeats from a sidecar goroutine while the real task stalled; the counter was doubly redundant (2026-06-17 b31002b8; 2026-06-21 21306ffe, transcript).
- The legacy {type: complete|blocked|errored} callback shape AND the 2026-05-08 "both shapes accepted indefinitely" dual-accept stance — reversed 2026-05-12 (nomenclature-resolution, artifact): new oneof shape only, legacy rejected.
- AsyncCallbackBody.events and the Heartbeat stream message — removed by executor-protocol-coherence (2026-06-16, 055468fc, transcript).
- Park.session_token / ResumeContext.session_token as named core-protocol fields, and resume-context generally — mis-leveled Claude-CLI concepts; executor-specific state rides behind the protocol (2026-06-14, 752fe200; removal 2026-06-16, 055468fc, transcript). This also moots the ClearResumeMetadata-after-RPC rule (2026-05-08, artifact).
- The hidden shouldForceRetryLoopGiveUp safety-net cap (silent default 100) overriding operator-declared retry counts — removed (2026-06-22, 10cf843b, transcript).
- Hard pause as a primitive — rejected; soft pause plus a pause-mode breakpoint with an empty matcher composes it (2026-05-24, instance-debugger, artifact).
- A pre-dispatch upstream-outcome check before dispatching a stale node — confirmed redundant under the lazy cascade and dropped (2026-05-05, reactive-loops-and-lifecycle-handlers, artifact).
- A scheduler concept and a migrate concept — deliberately not promoted (2026-05-11, artifact).
- Calling-side wire code moving into the SDK — stays rimsky-internal in the root module as runtime/peer (2026-05-24, repo-reorganization, artifact).
- The attribute_overrides_match_counts column — dropped in migration 020, now event-derived (2026-07-07 excise list, 3f71f90a, transcript). Supersedes the 2026-05-21 column-based counter design; the loud-unused-matcher observability goal presumably survives via events.
- The four per-node lifecycle-handler blocks (on_acquire_unavailable / on_executor_complete / on_executor_blocked / on_executor_errored) with resolve:/invalidate: — the 2026-05-05 surface was dismantled across the 2026-05-14 subscription refactor (invalidate: emits retired) and the 2026-05-23 policy decoupling (lifecycle-handler retirement; error_types is the operator surface). Do not restore handler-shaped config.
- Per-verb producer deadlines in ResolveClaimHandleTerminal — recommended, deliberately not landed (2026-05-04, layer-crystallization, artifact); an accepted gap, not an unmet promise.

## Corrections and restorations (drift-fight record)

- Parked rows claimed directly (missing phase='pending' predicate) — fixed in both dialects; wake only via wakeParkedNode (2026-05-08, artifact).
- InvalidateHandler never wired into supervisor RunArgs, so handler-emitted invalidates bypassed parked-awareness — fixed; single UnifiedInvalidate path (2026-05-08, artifact).
- Resume metadata cleared at request-build time, losing context on RPC failure — moved to after successful RPC (2026-05-08, artifact; surface since retired).
- Callback-determinism invariant only partially implemented: the phase-check tx commits before applyTerminal (which opens its own txs), leaving a narrow claimed_by-bounded TOCTOU window; the refactor was deferred while the invariant annotation remained (2026-05-22 divergences, artifact). Adjudication note: a finding pointing at this window is a known, recorded gap — restore-or-close per the invariant, not refute.
- The planned end-to-end atomic-staging scenario was replaced by shape-only tests; the fused store's terminal routing (verifier_failed→Abandon, Success→Commit) was never exercised end-to-end (2026-05-19, multi-instance-template-ergonomics divergences, artifact). Recorded coverage debt.
- Supervisor wasn't dialing DataProcessing producers at all — no candidate ever minted in a real stack; candidate_handle never reached the leaf — both fixed with the DataProcessors registry wiring (2026-06-02, rimsky-core-remediation, artifact).
- rimsky-entrypoint hard-coded the three-role spawn and ignored the container command while docs claimed role-by-command worked — fixed; false docs corrected (2026-06-02, rimsky-core-remediation, artifact). Precedent: CLAUDE.md/Dockerfile claims are not evidence a behavior exists.
- Round-1 validation of the liveness work caught silent scope-dropping behind a green build: attributes_delta discarded on Error/Park terminals, RegisterAsyncAck never called in production (restart recovery 404ed), max_runtime declared but unenforced, max_quiet_period defaulting 15m against the spec's 0 = disabled. User mandated zero scope cuts; round-2 confirmed all 13 TDs delivered (2026-06-17, b31002b8, transcript).
- The Pass-1 heartbeat sweep stopped early (doHeartbeat ticking against a dropped column) — ruled implementation drift, not design ambiguity; the spec had already prescribed complete retirement (2026-06-17, b31002b8, transcript).
- "A supervisor might miss a heartbeat by multiple seconds" framing rejected: in a stable system nothing may stall the scheduler; a stub-executor test needing two minutes indicates a rimsky bug (2026-06-21, 21306ffe, transcript). Precedent for adjudicating slow-timing findings: fix the performance bug, don't widen tolerances.
- SelectCandidates paused-filter join initially took unscoped FOR UPDATE, contending with pause/resume writes — narrowed to FOR UPDATE OF d (2026-05-24, instance-debugger divergences, artifact).
- Supervisor silently stamping http://0.0.0.0:9100 as callback_url — identified as a defect to fail fast on (2026-06-21, ecde6dd1, transcript).
