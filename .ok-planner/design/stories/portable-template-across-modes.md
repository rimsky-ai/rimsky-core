# The same template file runs in both modes without edits

## Story

As a rimsky user — a developer promoting a locally-authored template to production, or an operator adopting a template someone else authored — I can use the same template file in both the all-in-one and multi-container modes without editing it, so that there is no dev-vs-prod template dialect and locally-working templates are directly promotable.
