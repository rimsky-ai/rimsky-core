# Local user runs an ad-hoc template with zero config

## Story

As a developer iterating on templates against files on my own machine, I can run an ad-hoc template with one binary and one command — no config file, no docker or compose stack, no external service infrastructure — driving real bundled services end-to-end, so that my local iterate-on-a-template loop needs zero standing infrastructure.
