# The repo's source is split between a permissive protocols surface and a copyleft-or-commercial everything-else

Unsupported, because the artifact's own text does not settle its population and 79 files sit in the gap. The two-track split is real and mechanically maintained over the groups the decision names: the licensing map assigns the protocols module to the permissive track and exactly the eight groups the decision enumerates to the copyleft track with a commercial alternative, longest-prefix-match deciding overlaps; the checker stamps and verifies a per-file header matching each file's track and rejects a permissive file that imports a copyleft package, so the direction of the boundary is enforced rather than trusted, and an out-of-tree test builds a peer against the permissive surface alone and asserts its module graph never reaches a copyleft package. The population is where the decision and its enforcement disagree. The decision glosses "everything else" as eight code groups, all of which the module-layout concept owns, and that concept explicitly places non-code top-level entries outside its grouping — so on the decision's own terms the planner estate is not in scope. The licensing walker takes the opposite view: it hard-skips only version-control directories, requires every other directory to be listed as exempt, and the planner estate is listed neither as classified nor as exempt. Enumerating what that walker sees — every file with a source extension it recognizes, minus the exempt entries and generated bindings — gives 1794 files, of which 79 fall under neither track: the whole experiments tree, tracked in git since a prior audit run, carrying no license header, reported by the checker as unclassified source rather than defaulted to either side. Whether those files are project source that carries a license or estate the walker should skip is a judgment about what the project licenses, not something the corpus determines, so the confirmed gap is the unsettled scope itself.
