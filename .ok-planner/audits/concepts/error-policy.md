# The per-class action map, the retry budget, and the registration gates around them

Supported; all nine invariants check out. The evaluator is a flat per-class lookup over the four-action closed vocabulary with no per-attempt chain advance, returning give-up with an unknown-class reason when nothing matches, so fail-fast is the default and retry is opt-in. The node cap defaults to disabled and bounds the single per-dispatch counter across every class that occurs in that dispatch, synthesising a give-up with an exhausted-cap reason when reached. Infra-class faults take a separate path that never consults the map at all and retries under an internal supervisor cap of ten, overridden by the node's own cap whenever set — pinned by a test that asserts the constant and walks both the default and the node-override case. The four actions behave as described: retry is in place on the same dispatch row, the loop sleeping the computed delay and re-attempting the same operation with the same resolved attribute bag, the same dispatch id and no new row, for executor errors in the dispatch loop and for acquisition failures in the acquire loop alike; release-and-requeue releases the run's claims and re-enqueues the row, abandoning an uncoordinated claim on its own terminal while a held-subgraph claim only marks the run's holder failed and leaves the verb to the held resolution; pass settles with a fresh colour; give-up settles failed. The counter is persisted on the node-run row and starts at zero for a new run; the terminal-error payload carries it in both the attempt and retries-so-far fields, and the transient-retry signal embeds the same value in its type-path. Registration enforces both closed vocabularies as hard errors — the four actions, and the backoff kind and jitter — with no silent fallback at retry time, and range-checks each error-class key against the union of the node's executor's declared classes, the runtime-synthesized family including the reserved acquisition-failure prefix, and every reachable producer's declared classes, honouring a trailing wildcard, warning rather than rejecting when at least one peer vocabulary is known, and staying silent when none is. The acquisition-failure lookup tries the producer-declared class first and the synthetic family class second while the emitted signal keeps the most specific class, and the retry-cap-give-up chain is the only escalation a transiently unreachable peer gets — no separate alerting path exists.
