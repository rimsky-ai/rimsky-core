# The executor surface: two forms, the outcome vocabulary, scratch, and the eight invariants the concept claims

Supported. The protocol declares a single unary execute operation returning one outcome message whose variant set is exactly the three settling outcomes plus the async deferral, so the one-outcome-no-stream invariant is structural. All three settling variants carry a tag list; only the two run-terminating ones carry an attributes delta, and the park variant's delta field is retired in the proto — as is the resume-context request field, which is the whole of the third invariant. A park missing its resume timestamp is converted to an executor-protocol-violation error at the outcome-read boundary, with a unit test on both branches, so the concept's "required resume-at" holds. The async deferral's identifier is used only to look the run up, first in memory and then in a persisted registry that a restart-recovery test exercises; the two incremental per-run channels, keepalive and attribute writeback, each require the peer check plus a constant-time comparison of a bearer credential derived from the supervisor identity and the run id, and each rejects with 401 otherwise. The three orthogonal deadlines all exist and all bind: a per-node sync RPC deadline with a deployment default, and per-node quiet-period and total-runtime values denormalised onto the dispatch row and enforced by the conductor's sweep, covered by persistence-conformance cases. Executors advertise a declared tag set, checked twice — a registration hook rejects subscriptions referencing undeclared tags, and the settle path converts any emitted undeclared tag into a protocol violation. Both forms behave as described: out-of-process services are probed by the observability handshake, while the three bundled in-process handlers are advertised into the discovery cache at launch with a static marker the handshake and refresh loop both skip, so they genuinely never receive one. Scratch is carried on the request, written only by attaching it to a settling outcome (there is no mid-dispatch scratch channel), and the prior-disposition enum carries exactly the three superseding cases the concept names plus a none sentinel. The retry-with-backoff obligation on async delivery is an executor-side duty with no conformance check enforcing it on third parties; the one bundled executor that defers asynchronously honours it with five attempts on a doubling delay.
