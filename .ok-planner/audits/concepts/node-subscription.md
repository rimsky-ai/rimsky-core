# Receiver-side subscriptions: the subscribable subset, the inverse-edge map, and the four invariants the concept claims

Supported. The subscribable subset is not a hand-kept list but a derivation: the canonical emit taxonomy of eight patterns filtered through the cascade firing-gate predicate, which admits the terminal and attribute top-levels and nothing else, leaving exactly the three families the concept names — success terminals, classed error terminals, and per-key attribute-changed. A subscription naming anything else is rejected at registration by name, with park called out in its own message, and positional wildcards rejected in favour of trailing ones. The remaining three invariants hold as stated. The force-upstream-refresh flag is a pointer in the spec type and a nil check rejects any entry that omits it, so "required, no default applies" is enforced rather than defaulted; its runtime effect matches the description — on the receiver's invalidation the flagged sender is given a fresh pending run in the same frame and a wait-set row makes the receiver wait on it, with the edge map additionally rejecting a flag aimed at a fan-out node-type and detecting cycles. Substitution-ref coverage is checked at registration for both attribute and message refs, emitting a structured uncovered-ref finding with a suggested subscription entry, and a structured finding fails the validation result exactly as a plain error does. Self-subscription is exercised end to end by a scenario test that drives a node subscribed to its own terminal through repeated rounds inside one frame and asserts it both advances and quiesces. The inverse-edge map is built as the Boundaries section describes: declared subscriptions inserted under their sender, then one injected edge per node with no upstream of any kind, keyed to an empty-typed sender, patterned on the success terminal and with the refresh flag unset, where "no upstream" is tested against exactly the three disqualifiers named — non-self subscribes entries, upstream attribute substitution refs, and message-body consumption. Sub-graph internals are skipped, which is consistent rather than a fourth disqualifier: every non-entry internal must carry a subscribes edge under the sub-graph reachability rule, and the entry's upstream is the calling node that absorbs it. The map is a derived structure built from the spec without mutating it, and the canonical hash is taken over the spec bytes, so the derived view does not enter template identity.
